# ForeverQoL

Quality-of-life improvements for WoW Forever.

- **Bank transfers:** deposit and withdraw selected item types from character or account banks.
- **Quest-item markers:** flag items with no remaining known quest use and explain why in their tooltips.
- **Movable windows:** drag supported window titles, remember positions across sessions, and right-click to reset. Blizzard's normal panel rules still apply.
- **Commands:** `/fql` shows the loaded version; `/fql errors` reports blocked interface actions.
